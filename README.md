# Enterprise Multi-Site Campus Network Lab

Static portfolio site (plain HTML, no build step). Start at `index.html`.

## Publish on GitHub Pages
1. Create a repository, for example `campus-network-lab`, and upload everything in this folder.
2. Settings > Pages > Build and deployment > Deploy from a branch > `main` and `/ (root)`.
3. Your site appears at `https://YOUR-USERNAME.github.io/campus-network-lab/`.

## Before publishing
- Replace `Haziq` and the GitHub link in the header of each page.
- Add screenshots to `images/` (see `images/README.txt`).
- Check yellow note boxes and delete them once done.
- Confirm status table in Part 8 matches what you tested on GNS3.
