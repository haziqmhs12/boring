Part 6: DHCP and IP Helper

Series: Enterprise Multi-Site Campus Network on GNS3. Part 6 of 8.

VLAN clients broadcast a DHCP discover, and broadcasts do not cross subnets. A central DHCP server in the server block cannot hear them, so the distribution switches relay them.

How the relay works

With ip helper-address on a VLAN interface, the switch turns the broadcast into a unicast to the DHCP server, replaces the source with the SVI address and adds the gateway address so the server knows which pool to use. I configure it on the distribution layer because that is where each VLAN ends and routing begins.

interface vlan 13
 ip helper-address <dhcp-server-ip>

Pools

Before creating pools I list every subnet with its mask, gateway (the HSRP virtual IP where one exists), reserved range and first address to hand out. Pools are named site-name-VLANID, for example HQ-VLAN13.

Result

A PC in VLAN 13 received an address, mask and gateway from the central server across the routed network.
